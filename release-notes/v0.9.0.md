## 简体中文

Vyku v0.9.0 是公开预发布版本，主要用于验证 v0.8.0 到 v0.9.0 的升级体验、批量导入能力和首页资产看板体验。

### 更新内容

- 修复导入时可能覆盖已有数据的问题。
- 修复搜索筛选相关问题。
- 修复旧数据中存在提醒时，Windows 版启动后只在后台运行、无法显示窗口的问题。
- 将资产子分类、模板名称和模板字段接入三语显示。
- 首页“资产统计”改名为“资产看板”，并固定资产分类排序。
- 简化 CSV 导入模板，降低填写门槛。
- 清理静态分析提示，并补充相关回归测试。
- 固化发布包命名规则。

### 下载

- Windows x64 便携版：`vyku-v0.9.0-windows-x64-portable.zip`

### 升级说明

便携版用户可以解压新版后覆盖旧版程序文件。建议升级前先备份数据，或先解压到独立目录测试确认。

## 繁體中文

Vyku v0.9.0 是公開預發布版本，主要用於驗證 v0.8.0 到 v0.9.0 的升級體驗、批次匯入能力和首頁資產看板體驗。

- 首頁「資產統計」改名為「資產看板」，並固定資產分類排序。

- 清理靜態分析提示，並補充相關回歸測試。
- 固化發布包命名規則。

### 下載

- Windows x64 可攜版：`vyku-v0.9.0-windows-x64-portable.zip`

### 升級說明

可攜版使用者可以解壓新版後覆蓋舊版程式檔案。建議升級前先備份資料，或先解壓到獨立目錄測試確認。

## English

Vyku v0.9.0 is a public pre-release for validating the upgrade path from v0.8.0 to v0.9.0, batch import improvements, and the home asset dashboard experience.

### Changes

- Fixed an issue where imports could overwrite existing data.
- Fixed search filtering issues.
- Fixed a Windows startup issue where the app could stay in the background without showing a window when old reminder data existed.
- Localized asset subcategories, template names, and template fields across the three supported languages.
- Renamed the home “Asset Stats” section to “Asset Dashboard” and fixed the asset category order.
- Simplified the CSV import template to make importing easier.
- Cleaned up static analysis warnings and added regression tests.
- Documented the release package naming convention.

### Download

- Windows x64 portable: `vyku-v0.9.0-windows-x64-portable.zip`

### Upgrade Notes

Portable users can extract the new version and replace the previous application files. Backing up your data first is recommended, or extract to a separate folder for testing.
