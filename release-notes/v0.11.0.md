## 简体中文

Vyku v0.11.0 是数据安全与恢复版本，重点完善备份验证、恢复保护、附件健康检查和明文导出边界。

### 更新内容

- 增加 `.vbk` 备份包验证。
- 恢复前展示备份摘要和覆盖风险。
- 恢复失败后尝试自动回滚到恢复前数据。
- 增加附件健康检查，识别缺失文件、hash 异常和孤儿文件。
- 明确 CSV / JSON 不包含附件，不等于完整备份。
- 明文导出前提示敏感信息风险。

### 下载

- Windows x64 便携版：`vyku-v0.11.0-windows-x64-portable.zip`

### 升级说明

建议升级前先导出加密备份包。恢复备份前，v0.11.0 会先验证备份包并展示摘要；恢复失败时会尝试自动回滚。

## English

Vyku v0.11.0 is a data safety and restore release focused on backup verification, restore protection, attachment health checks, and clear plain-text export boundaries.

### Changes

- Added `.vbk` backup verification.
- Added pre-restore backup summaries and overwrite warnings.
- Added automatic rollback attempts when restore fails.
- Added attachment health checks for missing files, hash mismatches, and orphan files.
- Clarified that CSV / JSON exports do not include attachments and are not full backups.
- Added sensitive-data warnings before plain-text export.

### Download

- Windows x64 portable: `vyku-v0.11.0-windows-x64-portable.zip`

### Upgrade Notes

Export an encrypted backup before upgrading. Before restoring a backup, v0.11.0 verifies the backup package and shows a summary; if restore fails, it attempts an automatic rollback.
