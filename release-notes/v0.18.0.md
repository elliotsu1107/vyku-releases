# Vyku v0.18.0


> 更新日期 / Updated: **2026-10-26**（正式发布）

## 简体中文

V0.18.0-A 建立 Windows 与 Android 共用的视觉系统：三层视觉令牌、跟随系统/浅色/深色三种主题，以及七类核心页面的视觉改版。本版本不改动资产、提醒、附件、搜索、导入导出和备份恢复的业务语义。

### 更新内容

- 建立三层视觉令牌：原始值层（颜色、尺寸、间距、阴影、动效）、语义层（16 个语义色，浅色与深色各一套并接入 `ColorScheme`）、组件层（按钮、输入、卡片、列表、对话框、导航栏、Chip、SnackBar、AppBar 和进度指示等主题映射）。
- 新增字号刻度与中文字体族兜底策略；统计数字、金额和日期等使用等宽数字，位数变化不再引发布局跳动。
- 新增响应式断点与 `compact` / `medium` / `expanded` 三档布局，宽屏下内容区宽度受 840 约束。
- 新增跟随系统、浅色、深色三种主题；设置页「语言与显示」分组提供主题入口与选择子页，选择在重启应用后保留。
- 完成资产列表、搜索、资产详情、新增/编辑、提醒、附件和设置七类页面的视觉改版。
- 统一加载、空数据、无结果、错误、危险操作和保存反馈状态；聚焦环与禁用态视觉统一，键盘导航下焦点可见。
- 深色主题改用描边和表面亮度差表达层级，不再依赖阴影。
- 新增 `settingsTheme*`、`homeReminderFuture` 等文案键，简体中文、繁體中文和 English 三语保持完整。

### 下载与安装

- Windows：下载 `vyku-v0.18.0-windows-x64-portable.zip`。
- Android：下载 `vyku-v0.18.0-android.apk`。
- 同时下载对应 `.sha256` 文件，并在安装或解压前核对 SHA-256。
- Android 安装时仅临时允许当前浏览器或文件管理器“安装未知应用”，完成后恢复禁止安装设置。

以上文件名中的 `X.Y.Z` 为占位符，实际版本号在发布收口时确定；本次尚未生成安装包和校验值，本文件不提供下载链接。

本版本尚未完成的部分：Web 基础站点属 V0.18.0-B，尚未开工，也未通过验收；人工验收（Windows 与 Android 真机）尚未完成。在这些前置项完成之前，本文件不构成发布说明。

## English

V0.18.0-A establishes the visual system shared by Windows and Android: three layers of visual tokens, System / Light / Dark themes, and redesigned visuals for seven core page types. It does not change the business semantics of assets, reminders, attachments, search, import and export, or backup and restore.

### Changes

- Established three layers of visual tokens: primitive values (colors, sizes, spacing, shadows, motion), semantics (16 semantic colors, one set each for light and dark, wired into `ColorScheme`), and components (theme mappings for buttons, inputs, cards, lists, dialogs, navigation bars, chips, snack bars, app bars, and progress indicators).
- Added a type scale with a Chinese font-family fallback strategy; statistics, amounts, and dates use tabular figures so digit changes no longer shift layout.
- Added responsive breakpoints with `compact` / `medium` / `expanded` layouts and an 840 cap on content width on wide screens.
- Added System / Light / Dark themes, with a theme entry and selection subpage under Settings → Language & Display, and the choice is kept across restarts.
- Redesigned seven page types: asset list, search, asset detail, create/edit, reminders, attachments, and settings.
- Unified loading, empty, no-result, error, destructive-action, and save-feedback states; focus-ring and disabled-state visuals are unified, with visible keyboard focus.
- Dark theme now expresses hierarchy with borders and surface brightness instead of shadows.
- Added new copy keys such as `settingsTheme*` and `homeReminderFuture`, keeping Simplified Chinese, Traditional Chinese, and English complete.

### Download and Install

- Windows: download `vyku-v0.18.0-windows-x64-portable.zip`.
- Android: download `vyku-v0.18.0-android.apk`.
- Download the matching `.sha256` file and verify SHA-256 before installation or extraction.
- On Android, allow “Install unknown apps” for the current browser or file manager only temporarily, then disable it again after installation.

The `X.Y.Z` in these file names is a placeholder; the actual version number will be set when the release is finalized. No packages or checksums have been produced yet, and this file provides no download links.

Not yet complete: the web site belongs to V0.18.0-B and has not started or passed acceptance, and human acceptance on real Windows and Android devices is still pending. Until those prerequisites are done, this file is not release notes.
