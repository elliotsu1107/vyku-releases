# Vyku v0.18.1

> 更新日期 / Updated: **2026-11-07**

补丁版本：补齐**开源许可合规**入口，并修复 Web 站点的一批可见缺陷与门禁盲区。客户端与站点功能均无破坏性变更。

---

## 简体中文

### 新增

- **「开源许可」入口**：设置 → 关于下方新增入口，展示应用所用全部第三方组件（Flutter 框架、各插件）的 BSD / MIT / Apache 许可声明 —— 这是再分发应用的**合规要求**，此前缺失
- **官方站点上线**：<https://elliotsu1107.github.io/vyku/>（三语 18 页，仅部署构建产物）

### 修复

- **按钮被加上下划线**：Clay 主按钮与次级按钮（含首页主 CTA）曾继承正文链接的下划线，共 15 处；现显式去除
- **内联代码样式缺失**：60 处 `<code>` 退回浏览器默认等宽字体，现统一为 JetBrains Mono 栈、13px、浅暖灰底、4px 圆角
- **强调字重**：21 处 `<strong>` 由浏览器默认 700 收敛到 600，与站点字重口径一致
- **深色主题打印**：此前在深色主题下打印会得到浅色文字印在白纸上；现打印时临时切换为亮色语义
- **下载页信息**：发布后仍显示「暂无可用构建」占位；现显示真实版本、文件大小、SHA-256 与下载链接

### 工程

- `site.css` 按职责拆分为 `site.css`（基础层）与 `site-sections.css`（区块层），各自独立预算；打印样式独立为 `site-print.css`（`media="print"` 加载，不参与首屏）
- 站点门禁补齐 3 类此前可被绕过的盲区：`rgb()/hsl()` 形式的颜色、`outline:none`、`font-weight:bold`；新增「空锚点裸链接」判定
- 「零外链」规则新增唯一文档化例外：仅放行站点配置中声明的发布下载 URL，其余外链仍判失败

## English

### Added

- **Open-source licences page**: a new entry under Settings → About listing the BSD / MIT / Apache notices for every third-party component bundled with the app (the Flutter framework and its plugins). This is a **licensing requirement** for redistributing the application and was previously missing.
- **Official web site is live**: <https://elliotsu1107.github.io/vyku/> (18 pages in three languages; build artefacts only).

### Fixed

- **Buttons were underlined**: the Clay primary and secondary buttons (including the homepage's main CTA) inherited the body-link underline — 15 occurrences; now explicitly removed.
- **Missing inline-code styling**: 60 `<code>` spans fell back to the browser's default monospace font; they now use the JetBrains Mono stack at 13px on a warm tint with 4px radius.
- **Emphasis weight**: 21 `<strong>` elements dropped from the browser default of 700 to 600, matching the site's weight scale.
- **Printing in dark theme**: printing while the dark theme was active produced light text on white paper; printing now temporarily switches to the light semantic palette.
- **Download page data**: after the release the page still showed the "no build available" placeholder; it now shows the real version, file sizes, SHA-256 digests and download links.

### Engineering

- `site.css` was split by responsibility into `site.css` (foundation) and `site-sections.css` (page blocks), each with its own budget; print styles live in `site-print.css`, loaded via `media="print"` and not render-blocking.
- The site gates now cover three previously bypassable blind spots — `rgb()/hsl()` colour notation, `outline:none`, and `font-weight:bold` — plus a new check for empty-fragment bare links.
- The "zero external links" rule gained its single documented exception: only the release download URLs declared in the site configuration are allowed through; any other external link still fails.

## 下载与校验（Download & Verify）

> 本版本由 **GitHub Actions 自动构建**，构建成功后 Release 附件会自动生成。

| 平台 | 文件 |
|---|---|
| Windows x64（便携版 / portable） | `vyku-v0.18.1-windows-x64-portable.zip` |
| Android | `vyku-v0.18.1-android.apk` |

每个文件随附 `.sha256` 校验文件，下载后请先核对：

```bash
sha256sum -c vyku-v0.18.1-android.apk.sha256
sha256sum -c vyku-v0.18.1-windows-x64-portable.zip.sha256
```

**Android 签名**：沿用同一正式发布身份（`CN=Vyku Release, O=Vyku, C=CN`，证书 SHA-256 `7faa9691…8ccb9c`），
可直接覆盖升级 v0.18.0；若当前装的是 debug 包则**必须卸载重装**（签名不同）。

**最低系统版本**：Android 7.0（API 24）；Windows 未在构建配置中声明最低版本。
