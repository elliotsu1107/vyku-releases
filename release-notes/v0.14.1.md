# Vyku v0.14.1

> 更新日期 / Updated: 2026-07-20

## 简体中文

V0.14.1 完成 Android 正式发布基础，并让 Windows 与 Android 使用同一套安全备份和恢复流程。

### 更新内容

- Android 表单增加数字、日期、下拉、开关和多行输入，并定位首个校验错误。
- 附件支持拍照、选择图片和文件，保存前后校验 SHA-256。
- 通知权限按创建提醒场景请求，恢复权限后自动重新调度提醒。
- Windows 与 Android 可通过 schema 3 加密 `.vbk` 备份双向迁移，恢复前验证数据库和附件，失败时自动回滚。
- 增加自动和手动更新检查，仅访问公开 GitHub latest release。

### 下载与安装

- Windows：下载 `vyku-v0.14.1-windows-x64-portable.zip`。
- Android：下载 `vyku-v0.14.1-android.apk`。
- 同时下载对应 `.sha256` 文件，并在安装或解压前核对 SHA-256。
- Android 安装时仅临时允许当前浏览器或文件管理器“安装未知应用”，完成后恢复禁止安装设置。

V0.13.0 Android 包使用内部 debug 签名，不能覆盖安装本次正式包。请将 V0.14.1 视为全新安装；从 V0.14.1 起，同一正式签名且 `versionCode` 更高的版本可以覆盖升级。

schema 3 是首个公开备份兼容基线。未公开的 schema 1 / 2 测试备份不受支持。卸载 Android 应用会删除应用私有数据，迁移或重装前请先创建加密备份。

### 更新內容

- Android 表單新增數字、日期、下拉、開關和多行輸入，並定位第一個驗證錯誤。
- 附件支援拍照、選擇圖片和檔案，儲存前後驗證 SHA-256。

- Windows 與 Android 可透過 schema 3 加密 `.vbk` 備份雙向移轉，恢復前驗證資料庫和附件，失敗時自動回滾。
- 新增自動和手動更新檢查，只會存取公開 GitHub latest release。

### 下載與安裝

- Windows：下載 `vyku-v0.14.1-windows-x64-portable.zip`。
- Android：下載 `vyku-v0.14.1-android.apk`。
- 同時下載對應 `.sha256` 檔案，並在安裝或解壓縮前核對 SHA-256。
- Android 安裝時只暫時允許目前瀏覽器或檔案管理器「安裝未知應用程式」，完成後恢復禁止安裝設定。

V0.13.0 Android 套件使用內部 debug 簽名，不能覆蓋安裝本次正式套件。請將 V0.14.1 視為全新安裝；從 V0.14.1 起，相同正式簽名且 `versionCode` 較高的版本可以覆蓋升級。

schema 3 是第一個公開備份相容基線。未公開的 schema 1 / 2 測試備份不受支援。解除安裝 Android 應用程式會刪除應用程式私有資料，移轉或重新安裝前請先建立加密備份。

## English

V0.14.1 establishes the signed Android release baseline and gives Windows and Android the same safe backup and restore workflow.

### Changes

- Added number, date, select, switch, and multiline Android form controls with first-error focusing.
- Added camera, image, and file attachment sources with SHA-256 verification before and after storage.
- Added contextual notification permission requests and automatic reminder rescheduling after permission recovery.
- Added two-way Windows and Android migration using encrypted schema 3 `.vbk` backups, with database and attachment validation plus automatic rollback.
- Added automatic and manual update checks that only access the public GitHub latest release.

### Download and Install

- Windows: download `vyku-v0.14.1-windows-x64-portable.zip`.
- Android: download `vyku-v0.14.1-android.apk`.
- Download the matching `.sha256` file and verify SHA-256 before installation or extraction.
- On Android, allow “Install unknown apps” for the current browser or file manager only temporarily, then disable it again after installation.

The V0.13.0 Android package used an internal debug signature and cannot be upgraded in place to this signed package. Treat V0.14.1 as a fresh install. Starting with V0.14.1, a higher `versionCode` signed with the same release identity can upgrade in place.

Schema 3 is the first public backup compatibility baseline. Unpublished schema 1 / 2 test backups are not supported. Uninstalling the Android app removes its private data, so create an encrypted backup before migration or reinstallation.
