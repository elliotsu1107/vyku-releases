## 简体中文

Vyku v0.13.0 是 Android MVP 版本，在保留 Windows 能力的同时建立 Android 端基础可用闭环。

### 更新内容

- 新增 Android 平台工程和资产、提醒、设置三入口导航。
- 支持资产新增、查看、编辑、删除、标题与自定义字段搜索、分类筛选。
- 提醒列表区分已过期、30 天内和未来提醒，并可跳转关联资产。
- 支持图片应用内预览，以及 PDF / 文档交给 Android 系统应用打开。
- 支持简体中文、繁體中文、English。

### 安装说明

当前 Android 版本为内部测试 debug APK，可直接安装到兼容设备；尚未提供正式签名安装包。

### 数据与范围

Android 数据仅保存在当前设备的应用私有目录，卸载应用会清除数据。本版本不包含跨端同步、Android 完整备份恢复和系统通知完整体验。

## English

Vyku v0.13.0 is the Android MVP release. It establishes a usable Android baseline while retaining the existing Windows capabilities.

### Changes

- Added the Android platform project and three-entry navigation for Assets, Reminders, and Settings.
- Added asset create, view, edit, delete, title and custom-field search, and category filters.
- Added reminder states for overdue, due within 30 days, and future reminders, with navigation to the related asset.
- Added in-app image preview and Android system-app opening for PDFs and documents.
- Added Simplified Chinese, Traditional Chinese, and English support.

### Installation

The current Android build is an internal-test debug APK that can be installed directly on a compatible device. A signed public package is not available yet.

### Data and Scope

Android data stays in the app-private directory on the current device and is removed when the app is uninstalled. This release does not include cross-device sync, complete Android backup and restore, or the complete system-notification experience.
