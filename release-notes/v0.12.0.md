## 简体中文

Vyku v0.12.0 是多端 UI/UX 基线版本，重点统一资产列表、详情、编辑、提醒和设置等核心任务流，为后续 Android、iOS、macOS 和 Linux 客户端保持一致体验打基础。

### 更新内容

- 提炼轻量界面间距规则，统一页面留白、卡片和状态组件。
- 统一空状态和错误状态组件。
- 资产详情按基本信息、自定义字段、附件、提醒和危险操作分区。
- 创建 / 编辑资产时校验必填字段，并在字段附近显示错误。
- 存在未保存输入时，离开创建 / 编辑页会二次确认。
- 首页提醒入口区分已过期、即将到期和待处理，并可跳转关联资产。
- 设置页按语言与显示、数据与备份、导入导出、版本与关于分组。
- 补齐 V0.12.0 三语文案完整性测试。

### 下载

- Windows x64 便携版：`vyku-v0.12.0-windows-x64-portable.zip`

### 升级说明

建议升级前先导出加密备份包。本版本不变更数据库 schema，主要调整界面任务流和交互一致性。

## English

Vyku v0.12.0 establishes the multi-platform UI/UX baseline. It aligns the core task flows for asset lists, details, editing, reminders, and settings so future Android, iOS, macOS, and Linux clients can keep a consistent experience.

### Changes

- Added lightweight spacing rules for page padding, cards, and state components.
- Unified empty and error state components.
- Grouped Asset Detail into Basic Info, Custom Fields, Attachments, Reminders, and Danger Zone.
- Added required-field validation for Create / Edit asset forms, with field-level errors.
- Added discard confirmation when leaving Create / Edit with unsaved input.
- Improved the Home reminder entry with overdue, due-soon, and pending states, plus asset-detail navigation.
- Grouped Settings by Language & Display, Data & Backup, Import & Export, and Version & About.
- Added V0.12.0 trilingual copy completeness tests.

### Download

- Windows x64 portable: `vyku-v0.12.0-windows-x64-portable.zip`

### Upgrade Notes

Export an encrypted backup before upgrading. This release does not change the database schema; it focuses on UI task-flow and interaction consistency.
