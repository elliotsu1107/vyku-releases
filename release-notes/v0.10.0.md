## 简体中文

Vyku v0.10.0 是 Windows 产品化补强版本，重点完善便携版数据目录、备份互导、首页信息架构、批量导入流程和免费版轻量限制提示。

### 更新内容

- 增加 `portable` / `installer` 数据路径服务，便携版默认使用程序目录下的 `data/`，安装版使用系统应用文档目录。
- 支持便携版和安装版通过加密备份包互导数据。
- 首页补充待处理提醒区域，保留资产看板、分类入口和最近更新。
- 批量导入增加显式流程状态、覆盖统计、同文件重复标题跳过和免费版导入规模限制。
- 设置页增加数据与备份、数据路径、迁移说明和免费版轻量限制提示。
- 免费版资产上限调整为 200 个，单次批量导入限制为 50 条。
- 补齐相关简体中文、繁體中文、English 三语文案。

### 下载

- Windows x64 便携版：`vyku-v0.10.0-windows-x64-portable.zip`

### 升级说明

便携版用户建议先导出加密备份包，再解压新版。v0.10.0 会优先识别程序目录下的 `portable.flag` 或 `data/` 作为便携版数据目录；不要手动混用安装版和便携版数据库文件。

## English

Vyku v0.10.0 is a Windows productization release focused on portable data directories, encrypted-backup migration, home information architecture, batch import flow, and light free-tier prompts.

### Changes

- Added a `portable` / `installer` data path service. Portable builds use the `data/` directory next to the app; installer builds use the system application documents directory.
- Supported data migration between portable and installer builds through encrypted backup packages.
- Added pending reminders to the home screen while keeping the asset dashboard, category entry points, and recent updates.
- Improved batch import with explicit flow states, overwrite counts, duplicate-title skipping within one file, and free-tier import limits.
- Added Data & Backup, data path, migration guidance, and light free-tier prompts to Settings.
- Raised the free-tier asset limit to 200 assets. Single batch imports remain limited to 50 rows.
- Completed related Simplified Chinese, Traditional Chinese, and English copy.

### Download

- Windows x64 portable: `vyku-v0.10.0-windows-x64-portable.zip`

### Upgrade Notes

Portable users should export an encrypted backup before extracting the new version. v0.10.0 detects `portable.flag` or `data/` next to the app as the portable data directory. Do not manually mix installer and portable database files.
